# MarketGo - Sistema de tienda de abarrotes

Proyecto académico de Desarrollo Web. La versión profesional incluye datos de demostración ficticios y persistencia en `localStorage`.

## Acceso demo
- Administrador: `admin@marketgo.pe`
- Contraseña: `1234`

## Módulos principales
- Inicio y catálogo
- Productos y categorías
- Clientes
- Proveedores
- Empleados
- Órdenes de compra
- Recepción de mercadería
- Movimientos de inventario
- Carrito y pedidos
- Reportes y exportación CSV/Excel

## Datos de demostración
Los clientes y proveedores incorporados son ficticios para la presentación académica. Se pueden editar, activar/desactivar y registrar nuevos.

## Publicación
Sube `index.html` a GitHub Pages como archivo principal del repositorio.
